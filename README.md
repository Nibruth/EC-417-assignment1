## About

This repository contains my solutions for EC417 Assignment 1.

The assignment covers pairwise distance calculation, polynomial curve fitting, bias-variance decomposition, and exploratory data analysis using the California Housing dataset.

## Python Version

Python 3.12.1

## Requirements

Install the required Python packages using:

pip install -r requirements.txt

## How to Run

Run the following commands from the project folder:

python pairwise_distance.py

python polynomial_curve.py

python bias_variance.py

python housing_eda.py
